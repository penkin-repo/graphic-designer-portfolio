# 🎨 DESIGN.PRO - Портфолио графического дизайнера

Современное портфолио-сайт для графического дизайнера, специализирующегося на полиграфии, меню и рекламных материалах.

## 🚀 Технологии

- **Astro.js** - статическая генерация сайта для максимальной производительности
- **React** - интерактивные компоненты (модальные окна, фильтры, 3D эффекты)
- **Tailwind CSS** - современная стилизация
- **Framer Motion** - плавные анимации и переходы
- **Lucide React** - иконки

## 📦 Установка

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр продакшен-сборки
npm run preview
```

## ✨ Особенности

### 🎯 Производительность
- **Partial Hydration** - JavaScript загружается только для интерактивных компонентов
- **Статическая генерация** - мгновенная загрузка страниц
- **Оптимизированные изображения** - автоматическая оптимизация

### 🎨 Дизайн
- **3D эффекты** - интерактивные карточки с наклоном
- **Плавные анимации** - Framer Motion для всех переходов
- **Адаптивный дизайн** - отлично выглядит на всех устройствах
- **Премиум стиль** - теплая цветовая палитра, градиенты, тени

### 🔧 Функциональность
- **Фильтрация портфолио** - по категориям (Полиграфия, Меню, Листовки)
- **Модальные окна** - контактная форма
- **Роутинг** - главная страница и страница всех работ
- **SEO оптимизация** - мета-теги, семантическая разметка

## 📝 Настройка контента

### Добавление работ в портфолио

Отредактируйте файл `src/data/constants.ts`:

```typescript
export const PORTFOLIO_ITEMS = [
  { 
    id: 1, 
    title: "Название проекта", 
    category: "Меню", // или "Полиграфия", "Листовки"
    img: "URL изображения", 
    desc: "Описание проекта" 
  },
  // ... добавьте свои работы
];
```

### Изменение контактов

В компоненте `src/components/Modal.tsx` измените:
- Telegram: `https://t.me/username`
- Email: `design@example.com`
