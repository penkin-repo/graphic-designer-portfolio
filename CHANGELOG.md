# Обновления проекта

## ✅ Исправлено: 3D кубы

**Проблема:** 3D кубы отображались как плоские изображения.

**Решение:** 
- Переписан компонент `Cube3D.tsx` с использованием inline-стилей для CSS transforms
- Добавлена правильная perspective и transform-style: preserve-3d
- Добавлена keyframe анимация для вращения кубов
- Теперь кубы действительно 3D и вращаются в пространстве

## ✨ Добавлено: Детальные страницы портфолио

### Новые файлы:
1. **`src/pages/portfolio/[slug].astro`** - динамическая страница для каждого проекта
2. Обновлен **`src/data/constants.ts`** - добавлены детальные данные для каждого проекта

### Что включает детальная страница:

#### 📋 Информация о проекте:
- Полное описание проекта
- Клиент
- Год выполнения
- Категория

#### 🎨 Визуальный контент:
- Главное изображение проекта (большое)
- Галерея дополнительных изображений
- Адаптивная сетка изображений

#### ✅ Выполненные работы:
- Список всех услуг, предоставленных в рамках проекта
- Красивое оформление с иконками

#### 🔗 Навигация:
- Кнопка "Назад к портфолио"
- Блок "Другие проекты" - показывает похожие работы из той же категории
- Клик по любому проекту ведет на его детальную страницу

#### 💼 CTA секция:
- Призыв к действию "Обсудить проект"
- Кнопка связи с дизайнером

### Структура данных проекта:

```typescript
{
  id: number;
  title: string;
  category: string;
  img: string;
  desc: string;
  slug: string;                    // NEW - URL проекта
  fullDescription: string;         // NEW - полное описание
  client: string;                  // NEW - название клиента
  year: string;                    // NEW - год выполнения
  services: string[];              // NEW - список услуг
  images: string[];                // NEW - галерея изображений
}
```

### Роутинг:

- **Главная:** `/` - обзор портфолио (3 проекта)
- **Все работы:** `/portfolio` - полный список с фильтрацией
- **Детальная страница:** `/portfolio/[slug]` - например `/portfolio/aroma-menu`

### Примеры slug для проектов:
- `aroma-menu` - Меню для кофейни 'Aroma'
- `fitness-start-flyer` - Листовка 'Фитнес Старт'
- `product-catalog` - Каталог продукции
- `techlaw-business-card` - Визитка 'Tech Law'
- `sushi-bar-menu` - Сет для суши-бара
- `concert-poster` - Постер для концерта

## 🎯 Как использовать:

1. Кликните на любой проект в портфолио
2. Откроется детальная страница с полной информацией
3. Просмотрите галерею изображений
4. Изучите список выполненных работ
5. Посмотрите похожие проекты внизу страницы

## 📝 Как добавить новый проект:

Отредактируйте `src/data/constants.ts`:

```typescript
{
  id: 7,
  title: "Название проекта",
  category: "Меню", // или "Полиграфия", "Листовки"
  img: "URL главного изображения",
  desc: "Краткое описание",
  slug: "project-slug", // уникальный URL
  fullDescription: "Полное описание проекта...",
  client: "Название клиента",
  year: "2024",
  services: [
    "Услуга 1",
    "Услуга 2",
    "Услуга 3"
  ],
  images: [
    "URL изображения 1",
    "URL изображения 2",
    "URL изображения 3"
  ]
}
```
